# 메뉴 반응 기능

메뉴 코너별로 👍 / 😋 / 😐 를 누를 수 있는 기능입니다.
반응 1개는 `날짜:층:코너` 키 하나에 붙습니다. 예: `2026-08-26:f20:ilpum`

코너 키는 `index.html`의 `WEEKS` 데이터 구조를 그대로 따릅니다.

| 층 | 코너 키 |
|---|---|
| `f20` | `hansik`, `ilpum`, `special` |
| `f10` | `lunchbox`, `brunch`, `salad` |

## 현재 상태: `local` 모드

`index.html` 상단의 설정이 이렇게 되어 있습니다.

```js
const RX_CFG={mode:'local',url:'',anonKey:''};
```

`local` 모드는 **누른 사람의 브라우저에만** 저장됩니다.
서로의 반응이 보이지 않으므로 아직 커뮤니티 기능이 아니고, 화면과 조작감을 확인하는 용도입니다.
이 상태에서는 페이지 하단에 그 사실을 알리는 안내문이 표시됩니다.

## 공유 모드로 전환하기 (Supabase)

### 1. 프로젝트 만들기

[supabase.com](https://supabase.com) 에서 무료 프로젝트를 생성합니다.

### 2. 테이블 만들기

Supabase 대시보드의 **SQL Editor** 에 아래를 붙여넣고 실행합니다.

```sql
create table if not exists public.menu_reactions (
  id         bigint generated by default as identity primary key,
  menu_key   text not null,
  voter      text not null,
  emoji      text not null check (emoji in ('good','yum','meh')),
  created_at timestamptz not null default now(),
  unique (menu_key, voter)
);

create index if not exists menu_reactions_key_idx
  on public.menu_reactions (menu_key);

alter table public.menu_reactions enable row level security;

-- 누구나 카운트를 읽을 수 있음
create policy "read all" on public.menu_reactions
  for select using (true);

-- 누구나 반응을 남길 수 있음. 값 형식만 제한.
create policy "insert any" on public.menu_reactions
  for insert with check (
    char_length(menu_key) between 1 and 64
    and char_length(voter) between 8 and 64
  );

-- 같은 사람이 다시 누르면 갱신 / 취소되어야 하므로 필요
create policy "update any" on public.menu_reactions
  for update using (true) with check (true);
create policy "delete any" on public.menu_reactions
  for delete using (true);
```

### 3. 설정값 채우기

Supabase 대시보드 → **Project Settings → API** 에서 두 값을 복사해 `index.html`에 넣습니다.

```js
const RX_CFG={
  mode:'supabase',
  url:'https://<프로젝트ID>.supabase.co',
  anonKey:'<anon public key>'
};
```

`anon public key`는 **공개 배포용 키**라서 이 파일에 넣고 커밋해도 됩니다.
실제 권한은 위에서 만든 RLS 정책이 결정합니다.
반대로 `service_role` 키는 **절대 넣으면 안 됩니다** — 그 키는 RLS를 무시합니다.

### 4. 확인

페이지를 열고 반응을 누른 뒤, 다른 브라우저(또는 시크릿 창)에서 같은 날짜를 열어 카운트가 함께 올라가는지 봅니다.
하단의 `local` 모드 안내문이 사라져 있어야 정상입니다.

## 알아둘 점

- **로그인이 없으므로 표는 신뢰할 수 없습니다.** `voter`는 브라우저가 만들어 `localStorage`에 저장하는 임의 문자열입니다. 브라우저 저장소를 지우거나 시크릿 창을 쓰면 같은 사람이 다시 누를 수 있고, 마음먹으면 얼마든지 조작할 수 있습니다. 점심 메뉴 인기 참고용으로는 충분하지만, 그 이상의 의미를 부여할 수는 없습니다.
- **RLS 정책상 남의 반응도 지울 수 있습니다.** 익명 취소 기능을 만들려면 피할 수 없는 부분입니다. 이걸 막아야 한다면 로그인(Supabase Auth)을 붙여 `voter`를 `auth.uid()`로 바꿔야 합니다.
- **사이트가 공개되어 있습니다.** GitHub Pages로 누구나 접근할 수 있으니, 반응 수도 외부에 노출된다는 점을 감안해 주세요.
- 저장에 실패하면 카운트를 원래대로 되돌리고 해당 코너 아래에 실패 안내를 띄웁니다. 반응이 조용히 사라지지는 않습니다.
